# Temporary design preview

Open `index.html` directly in a browser; no installation/server.

300 × 300 default; 150% is for inspection. Right-click → Edit goal or use the preview toolbar. Changes reset on reload. Accepted goal is centered vertically/horizontally, with centered lines.

Surrounding wallpaper, caption, header, and toolbar are preview aids, not app features. No native glass, dragging, storage, or Windows integration is implemented. `preview.png` predates centering; use HTML as the current reference.

Provisional mountain image: https://images.unsplash.com/photo-1454496522488-7a8e488e8606?w=1200&q=90&fit=crop . Verify creator/license or replace before distribution; this prototype asserts no final artwork rights.
